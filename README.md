**Project Title**
# Methods-in-OOPs
 **Description**

An overview of instance, class, and static methods in object-oriented programming and how they differ in behavior and use.
**Introduction**

This project was created to help beginners understand the differences between various types of methods in Python's object-oriented programming system.
**Features**

Explains instance, class, and static methods
- Simple examples with comments
- Beginner-friendly structure
